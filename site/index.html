RESEARCH STATUS

Positive expected value is a model estimate. Profitability needs a credible, time-ordered evaluation and an independent forward record.

MAE / RMSEPrediction error in total points; lower is better. Compare candidates on the same games.

ROI / 95% intervalEstimated return per unit staked and its uncertainty. An interval spanning zero does not establish profitability.

Brier scoreProbability error for the stated evaluation sample; lower is better. Calibration matters more than confidence.
